## 二、完成度计算（核心公式）

文件位置：[app/core/scheduler.py](file:///e:/item/wxread/app/core/scheduler.py#L27-L50)

```python
@dataclass
class DailyPlan:
    date: str                    # 日期键 YYYY-MM-DD
    target_minutes: int          # 当日随机目标（分钟）
    skill_baseline_sec: int      # Skill 网关返回的今日已读秒数
    session_accum_sec: int       # 本次启动后本地累加秒数
    success_count: int          # 成功次数
    fail_count: int              # 失败次数

    @property
    def completed_sec(self) -> int:
        """Skill 混合方案：基线 + 本地累加"""
        return self.skill_baseline_sec + self.session_accum_sec

    @property
    def completed_minutes(self) -> int:
        return self.completed_sec // 60

    @property
    def started_minutes(self) -> int:
        """降级：本地估算"""
        return int((time.time() - self._start_ts) / 60)

    @property
    def completed_minutes(self) -> int:
        """最终取 max(Skill, 本地)"""
        return max(self.completed_sec, self.started_minutes * 60) // 60
```

### 刷新周期

- **启动时**：立即拉取 Skill 网关基线（今日已读权威秒数）
- **每 5 分钟** 或 **每 10 次成功阅读**：刷新 Skill 基线，`session_accum_sec` 归零

文件位置：[app/core/scheduler.py](file:///e:/item/wxread/app/core/scheduler.py#L507-L588)

```python
def _maybe_refresh_skill_baseline(self, plan: DailyPlan) -> None:
    """按时间或成功次数周期刷新 Skill 基线。"""
    now = time.time()
    # 条件1：距离上次刷新超过 5 分钟
    time_expired = (now - plan._last_skill_ts) > 300
    # 条件2：成功次数累计超过 10
    count_expired = plan.success_count - plan._last_skill_count >= 10

    if time_expired or count_expired:
        new_baseline = self._fetch_skill_baseline()
        if new_baseline is not None:
            plan.skill_baseline_sec = new_baseline
            plan.session_accum_sec = 0  # 归零，从新基线继续累加
            plan._last_skill_ts = now
            plan._last_skill_count = plan.success_count
```

### 规则

```
首次启动（config 无 daily_plan 或 date ≠ 今日）
  → 在 [min_hours, max_hours] 区间随机取值
  → 写入 config.json
  → 复用

当日多次启动
  → 命中 date = 今日
  → 直接复用，不再随机

次日启动
  → date 不匹配
  → 重新随机取值
  → 覆盖写入
```

## 六、主循环核心代码

文件位置：[app/core/scheduler.py](file:///e:/item/wxread/app/core/scheduler.py#L132-L294)

```python
def run(self):
    """调度器主循环。"""
    log.info("调度器已启动")
    
    # 1. 启动准备：刷新当前书、验证登录态
    self._api.refresh_current_book_from_shelf()
    if not self._api.check_session():
        self._api.ensure_session()
    
    # 2. 启动随机延迟（30~90s）
    startup_delay = random.uniform(30, 90)
    self._interruptible_sleep(startup_delay)
    
    # 3. 主循环
    while not self._stop_event.is_set():
        # 3.1 健康巡检
        self._maybe_run_health_check()
        
        # 3.2 确保今日计划
        plan = self._ensure_daily_plan()
        
        # 3.3 完成度检测
        if plan.completed_min >= plan.target_minutes:
            self._notify_daily_done(plan.completed_min)
            self._sleep_till_next_minute(plan.date)
            continue
        
        # 3.4 刷新 Skill 基线
        self._maybe_refresh_skill_baseline(plan)
        
        # 3.5 执行一次阅读
        ok = self._do_one_reading_step(plan)
        
        # 3.6 计算间隔
        base = random.uniform(30, 45)
        jitter = random.uniform(0.85, 1.15)
        interval = base * jitter
        if plan.success_count % 20 == 0:  # 每 20 次长休息
            interval += random.uniform(60, 180)
        if not ok:  # 失败冷却
            interval += random.uniform(30, 60)
        
        # 3.7 等待
        self._interruptible_sleep(interval)
```

## 七、CDP 登录成功后的自动流程

文件位置：[app/ui/cdp_login_dialog.py](file:///e:/item/wxread/app/ui/cdp_login_dialog.py#L771-L779)

```python
def _on_login_success(self, cookies):
    """CDP 登录成功后自动流程。"""
    # 1. 持久化 Cookie
    self._persist_cookies(cookies)
    
    # 2. 获取书架（优先 Skill /shelf/sync）
    books = self._fetch_bookshelf(cookies)
    
    # 3. 获取章节池（优先 Skill /book/chapterinfo）
    for book in books[:5]:  # 前 5 本书
        chapters = self._fetch_chapters_for_book(cookies, book["bookId"])
    
    # 4. 拉取 Skill 阅读统计基线
    self._api.fetch_daily_reading_summary()
    
    # 5. 发送登录成功推送
    self._notify_login_success(books)
```
