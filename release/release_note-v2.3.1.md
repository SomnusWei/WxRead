## 本次更新

### 📊 今日阅读统计修复（v2.3.1）

- **修复目标显示不一致**：主界面统计卡片此前硬编码「目标 120 分钟」，与阅读状态区的当日目标（按配置区间随机生成）各显示各的。现统一从当日计划读取，两处完全一致；周 / 月 / 年参考进度同步联动；当日计划尚未生成时显示「目标待生成 · 启动阅读后自动设定」。
- **修复 Skill 官方时长刷新后界面不更新**：旧逻辑对「本地估算时长」与「微信读书官方时长」取较大值，而本地每次上报固定 +45 秒的估算系统性偏大（例如本地 49 分钟、官方仅 36 分钟），导致官方数据永远无法纠正显示。现改为以官方数据为权威基线（官方值 > 0 直接覆盖，之后继续实时累加；官方暂时返回 0 或接口失败时保留本地值不清零；跨天自动重置）。
- **卡片实时刷新**：统计卡片由原来每 30 分钟（Skill 刷新）才更新，改为每轮上报后即时刷新，与状态区「已完成」分钟数保持一致。
- 校准幅度 ≥ 1 分钟时日志会显式输出「今日时长已按微信读书官方数据校准上调 / 下调：X → Y 分钟」，看到数字下调是官方口径纠偏，不是丢进度。

### 🛡️ 阅读风控自动防线（v2.3.0 起）

- read 上报结果 8 类精细分类（空响应 / 错误码 / 网络异常 / 登录态失效等），失败日志直接附带类型。
- 登录态正常但阅读接口连续 3 次返回 HTTP 200 空响应（服务端静默丢弃的软风控特征）即自动判定，**立即停止一切上报**，避免持续重试加重处罚。
- 指数退避冷却：60 → 120 → 240 分钟逐档翻倍（360 分钟封顶），冷却结束自动试探，成功一次即自动恢复；主界面实时显示冷却倒计时。
- WxPusher「🚨 阅读风控提醒」：命中风控立即微信通知，同类告警 3 小时最多一条，限频记录持久化，重启不重复轰炸。

### 📚 套装书 / 公众号合集自动永久跳过（v2.3.0 起）

- 遇到 `CB_` / `MP_` 等非数字 bookId（章节实为多本子书，无法自动上报）时自动永久拉黑并立即换书，不再整夜卡死在同一本书上重试。
- 黑名单持久化，重启程序、书架重新同步后标记都不丢失。
